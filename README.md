# TeleZyra

TeleZyra is a modern social media brand for sharing ideas, trends, and creative content.

This repository now contains a responsive landing website for the TeleZyra project. It presents the brand, product concept, audience, roadmap, and waitlist flow in a polished social-media-inspired design.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints in the terminal.

## Build

```bash
npm run build
```

## Notes

- Project name and visible brand copy are set to **TeleZyra**.
- The current checkout did not include design images or PDFs, so the site was built from the available TeleZyra project description and structured so design/content from those files can be incorporated when added.
